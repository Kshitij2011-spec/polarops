# Command Center API Mapping

This document provides the definitive traceability matrix connecting every section and operational value of the PolarOps Insight Command Center (`/command-center`) to its authoritative backend API source, backend service, data transformation, and verification tests.

## Traceability Matrix

| New UI Section | Backend Endpoint | Backend Service | Transformation / Presentation Adapter | Mock Removed? | Verification Test |
|---|---|---|---|---|---|
| **Header Status & Subtitle** | `GET /station/overview?station_id={id}` | `station_service.get_station_overview` | Formats station name, environment mode (`WINTER`), and station status (`DEGRADED`/`NOMINAL`). | ✅ YES (Replaces hardcoded status "OPERATIONAL") | `command_center_integration.spec.ts` |
| **Operational Metric: Generation & Power** | `GET /station/overview?station_id={id}` & `GET /assets/G-02/telemetry` | `station_service` & `asset_service` | Calculates active power load, generator status, and rated capacity. | ✅ YES (Replaces `demoMetrics[0]`) | `command_center_integration.spec.ts` |
| **Operational Metric: Fuel Autonomy** | `GET /station/overview?station_id={id}` | `station_service.get_station_overview` | Extracts `fuel_runway_days` (81 days) and `fuel_quantity_liters` (64,800 L). | ✅ YES (Replaces `demoMetrics[1]`) | `command_center_integration.spec.ts` |
| **Operational Metric: Ambient Weather** | `GET /station/overview?station_id={id}` | `station_service.get_station_overview` | Extracts `temperature_celsius` (-18.4°C), `wind_speed_knots` (24 kts), `wind_chill_celsius` (-28.2°C), `conditions`. | ✅ YES (Replaces static personnel metric with real weather) | `command_center_integration.spec.ts` |
| **Operational Metric: Active Incidents** | `GET /station/overview?station_id={id}` | `station_service.get_station_overview` | Extracts `active_incidents_count` and primary severity. | ✅ YES (Replaces `demoMetrics[3]`) | `command_center_integration.spec.ts` |

| **Incident Timeline & Activity Stream** | `GET /events?station_id={id}&limit=10` | `event_service.get_operational_events` | Formats ISO timestamps, severity badges, and event summary text. | ✅ YES (Replaces `demoTimeline` & `demoActivities`) | `command_center_integration.spec.ts` |
